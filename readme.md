# Radar Moving Target Indicator (MTI), Moving Target Detection (MTD), and Constant False Alarm Rate (CFAR) in MATLAB code

MTI radar utilizes the Doppler shift caused by moving targets to distinguish between moving and stationary targets. In pulsed radar systems, this Doppler shift is manifested as phase changes in the echo signals returned between successive radar pulses.
The precise time it takes for an echo signal to return to the radar is not fundamentally important; what matters is whether there is a change in the time between pulses. The change in time can be determined by comparing the phase of the echo signal with that of the radar's reference oscillator. If the target moves between pulses, the phase of the echo pulse will change.
The key characteristic of MTI radar systems that suppresses static clutter is the absence of significant phase changes in the echo signals returned from consecutive emission pulses. What needs to be clarified here is that the operation of the MTI system does not rely on frequency discrimination between the target and clutter. Frequency discrimination requires long exposure times to multiple targets rather than two pulses separated by one pulse repetition interval (PRI).
Long exposure times are a fundamental characteristic of moving target detection (MTD).
MTD (Moving Target Detection) is a bandpass filter group, meaning it has multiple inputs and outputs. It can be implemented using an FIR (First-Order Linear) group, but generally, it is realized through FFT (Fast Fourier Transform). This means processing the same distance units of echo signals from different pulse groups with FFT. With N inputs, we get N outputs. CACFAR (Coherent Acoustic Radar Forward Transform) is used to detect and judge targets based on these N outputs. If there are targets, the peak in one of these outputs will be the most significant, which could potentially indicate the position information of the target. Based on this positional information, the Doppler value of the moving target can be determined. The key difference between MTD radar systems in distinguishing moving targets from clutter lies in their velocity differences.Due to the different speeds, the Doppler frequencies of the echo signals are not equal. Therefore, by distinguishing between clutter and moving targets based on their Doppler frequencies, Moving Target Detection (MTD) can not only filter out clutter but also differentiate targets with different speeds, significantly improving the ability to detect moving targets in clutter backgrounds.
Constant False Alarm Rate (CFAR) is abbreviated as Constant False Alarm Rate. In radar signal detection, when the intensity of external interference changes, the radar can automatically adjust its sensitivity to maintain the false alarm probability unchanged, this characteristic is known as Constant False Alarm Rate. There are two methods to obtain CFAR: parametric and non-parametric methods.

CFAR detection is an important component of automatic target detection in radars, which can be used as the first step in extracting targets from SAR images and serves as the foundation for further identification of targets. The false alarm rate refers to the probability that reconnaissance equipment misidentifies noise or other interference signals as threat radiation source signals within a unit time. CFAR detection proves the stability and reliability of the detection algorithm.

The requirement for maintaining a constant false alarm probability in radar signal CFAR detection is mainly due to the fact that in radar signal detection, the optimal detection often adopts the Naive-Pierson criterion, i.e., maintaining a constant false alarm probability while maximizing the probability of correct detection. During the detection process of radar signals, if there are too many false alarm targets, it will lead to the computer's processing capacity reaching saturation, inevitably affecting the detection of normal targets. Maintaining a constant false alarm rate in radar signal detection can effectively solve this problem, so CFAR detection has great practical significance. However, unfortunately, in radar signal detection, due to the randomness of various interference intensities, using fixed thresholds will make it difficult to ensure the constant false alarm probability detection of signals.
